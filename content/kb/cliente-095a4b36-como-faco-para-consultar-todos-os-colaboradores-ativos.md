# Como faço para consultar todos os colaboradores ativos?

Para consultar os colaboradores ativos, elegíveis e inativos, confira no menu a aba "Beneficiários". Lembrando que os colaboradores só aparecerão neste campo após concluírem o cadastro no aplicativo. Portanto, se você os cadastrou e eles não refletem no Portal RH, é porque ainda não se cadastraram.
