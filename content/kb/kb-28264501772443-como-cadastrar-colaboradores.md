# Como cadastrar colaboradores?

Você pode incluir novos beneficiários fazendo o upload da sua base de colaboradores no Portal RH via “atualizar base”. Nesta seção, sua empresa precisará subir uma base de dados, assim conseguimos garantir mais assertividade nos processos, evitando possíveis erros. Confira:

1.  Acesse o Portal RH;
2.  No menu lateral, clique em **Atualizar base**;
3.  Selecione um modelo de arquivo para fazer download;

-    O modelo de arquivo é o template que você usará para formatar o arquivo excel da sua base de colaboradores, para ser processada corretamente no Portal RH.

1.  Faça upload da base no portal;
2.  Aguarde a análise.

-   O Portal RH carregará os registros dos colaboradores da planilha.

1.  Revise os dados para aprovar ou rejeitar.

-   Ao fim da análise, você deve clicar em “Revisar relatório” para então aprovar ou recusar as alterações. Se estiver tudo certo, clique em "Confirmar atualização" e autorize o envio.

1.  Com a base atualizada, os seus colaboradores já podem realizar o cadastro no app para utilizar o benefício.

-   Os colaboradores só aparecerão na aba de **beneficiários** após efetuarem o cadastro no  aplicativo.
-   Além disso, você poderá conferir todos os seus registros de importação e visualizar o relatório aprovado novamente sempre que necessário em “Histórico de atualizações”
-   Se você já enviou uma base de dados antes, o Portal RH irá comparar com a nova para identificar colaboradores que não estão mais presentes. Se a nova base for validada, os colaboradores ausentes serão removidos do benefício.
