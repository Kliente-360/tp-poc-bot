# Meu check-in vale para o meu dependente também?

**Não.** Cada usuário da TotalPass, sendo titular ou dependente, possui acesso único no nosso App, no qual cada um terá o seu próprio check-in para conseguir treinar. Lembrando que o check-in é intransferível.
