# Como dar o aceite para o colaborador usar o TotalPass?

Caso a sua empresa tenha o cadastro manual, ou seja, vocês precisam aprovar o cadatro dos colaboradores no Portal RH, primeiro, o colaborador se cadastra no app e a solicitação para aprovação irá refletir na aba "Solicitações". Agora, se vocês possuem a opção no menu "Atualizar Base", o RH deve importar a base informando CNPJ e CPF dos colaboradores. A base tem como objetivo principal aprovar o cadastro dos colaboradores de forma automática. Feito isso, eles estarão aptos para seguirem com cadastro pelo aplicartivo.
