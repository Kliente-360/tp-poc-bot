# Como remover um colaborador manualmente?

Na aba “Beneficiários”, pesquise o nome do colaborador e selecione o botão “desligar”. O usuário irá cumprir o ciclo vigente e, ao final, ficará inativo. Observação: Este passo a passo só é possível para usuários que possuem cadastro no app. Caso queira desligar um colaborador que não realizou o cadastro no app, será necessário atualizar a base, importando um arquivo com todos os CPFs, exceto dos colaboradores que foram desligados. Assim, o sistema irá comparar a base atual com a anterior e irá desligar os CPFs que não foram incluídos.
