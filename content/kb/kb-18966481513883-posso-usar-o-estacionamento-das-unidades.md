# Posso usar o estacionamento das unidades?

Cada academia possui sua própria política para uso do estacionamento.

No app, ao selecionar a academia desejada, você pode verificar no campo **“O local te oferece”** se há estacionamento disponível.

Na dúvida, consulte a unidade para confirmar se há isenção ou desconto para alunos TotalPass.
