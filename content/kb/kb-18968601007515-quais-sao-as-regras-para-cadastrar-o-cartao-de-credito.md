# Quais são as regras para cadastrar o cartão de crédito?

Primeiramente, essa forma de pagamento deve estar disponível para sua empresa.

Caso esteja, você pode cadastrar um cartão com a função crédito disponível. Não poderá ser cadastrado cartão de débito, crédito pré-pago ou cartão sem fundos.

É necessário que o seu cartão esteja habilitado para compras virtuais! É importante que você cheque isso para evitar eventuais dificuldades.
