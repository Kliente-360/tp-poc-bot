# Como realizar o desligamento de colaboradores?

Para desligar um colaborador (inativar seu cadastro) você possui dois caminhos: 
 
1. Desligar de forma manual: Vá à aba “Beneficiários”, procure o colaborador e clique em “desligar”. Este passo só vale para quem possui cadastro no app.
2. Atualização de base: Suba uma nova base sem informar o CPF do colaborador que deseja inativar. Assim, o sistema irá comparar a base atual com a anterior e desligar o CPF que não foi incluído. 
Se precisar de mais alguma coisa, estamos aqui para ajudar!
