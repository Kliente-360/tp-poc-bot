# Como posso realizar o desligamento manual de um colaborador no sistema?

É possível realizar o desligamento via Portal RH. Siga os passos: acesse o menu lateral esquerdo “Beneficiários”, procure pelo colaborador que deseja desligar, clique no botão de ação “…” e selecione "desligar". Este passo é válido somente para colaboradores que possuem cadastro no aplicativo.
